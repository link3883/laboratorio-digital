
# Laboratorio Digital

Un espacio experimental para explorar desarrollo web,
interacciones digitales y diseño de interfaces.

## Estado del proyecto

Versión: 0.1.0  
Estado: En desarrollo

## Objetivo

Construir un sitio web estático con HTML, CSS y JavaScript,
aplicando principios de Ingeniería de Software y control
de versiones con Git.

## Requisitos iniciales

- [ ] Página principal adaptable a distintos dispositivos.
- [ ] Estilo visual experimental.
- [ ] Al menos una interacción funcional con JavaScript.
- [ ] Separación entre estructura, estilos y lógica.
- [ ] Código versionado con Git.
- [ ] Publicación mediante GitHub Pages.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Ejecución

Abrir `index.html` en un navegador web.
